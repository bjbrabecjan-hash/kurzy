# Filipino Course Guide

A mobile-first Tagalog/English walkthrough for Filipino residents who need to register for the Czech adaptation and integration course.

The guide does not collect personal information or replace the official portal. It explains the process and links users to `kurzy.frs.gov.cz` when an official action is required.

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Content basis

The prototype content is based on the official introductory information and registration pages reviewed on 30 June 2026. Legal and operational details should be reviewed periodically before production use.
